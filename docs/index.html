What's inside

features

18 figures

Wire globe, cube, torus, tunnel, radar, helix… one per collection, turning as a video loop with a glitch entrance — or "light" (a still that breathes), or still.

Sticker sheets

Every game on one of 16 grey patterns, with its picture as a Polaroid or a die-cut logo, plus stickers by the level you pick (0–5).

10 accents

White, red, orange, yellow, acid, green, ice, blue, violet, pink — each drawn ahead, so switching is instant.

Charging screen

On the charger and untouched for 15 s: the boot screen with a turning figure, glitch bursts and the charge. Any button — the figure glitches back in.

Settings app

escape-UI in PORTS: figure per collection, pattern per game, cover picture, boot logo, colours. A file copy when the variant library is drawn.

Any setup

Custom collections, consoles, favourites, last played; names in Cyrillic, Japanese, Korean; names with : or ?; unscraped games.

Install

install

  1. Download escape-ui-theme-vX.Y.zip from Releases.
  2. Copy themes and roms from the archive to the root of SHARE (/userdata) — over the network or with the card in a computer.
  3. On the Brick: UPDATE GAMELISTS (or reboot), then start EscapeUI from PORTS.
  4. Setup screen: A — turn the theme on, X — the same with custom collections on the home screen, B — leave.

Want it all drawn ahead on a PC (faster, the Brick stays idle)? See the guide or the README.
